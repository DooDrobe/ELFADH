# EL-FADH Bimbel Landing Page

This is the official landing page for **EL-FADH Bimbel**, built with a modern web stack to ensure high performance, SEO optimization, and a seamless user experience.

## Technology Stack

- **Framework:** Next.js 14+ (App Router)
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Icons & UI:** Lucide React, Headless UI, Framer Motion

## Routing Structure

The application follows the Next.js App Router structure:

- `/` (Home): The main landing page featuring the hero section, homework clinic value proposition, and activity gallery.
- `/programs`: Detailed curriculum information segmented by grade (SD, SMP, SMA).
- `/pricing`: Transparent course catalog with expandable sections.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
